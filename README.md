# 坦克大战 (Battle City)

一个使用纯 HTML + CSS + JavaScript（Canvas）实现的经典坦克大战游戏，无需任何依赖，双击 `index.html` 即可在浏览器中游玩。

## 玩法

- **目标**：消灭所有敌方坦克，并保护屏幕下方的基地（🦅）不被摧毁。
- **移动**：方向键 或 `WASD`
- **射击**：空格 或 `J`
- **暂停**：`P`
- 支持触屏虚拟按键（方向键 + 射击按钮）。

## 游戏要素

- 三种敌人：普通（红）、快速（蓝）、装甲（金，需两发子弹）
- 可破坏的**砖墙**、不可破坏的**钢墙**（火力满级可击穿）、**水面**、可藏身的**树林**
- 道具掉落：
  - 🛡 护盾 —— 临时无敌
  - ❤ 生命 —— 增加一条命
  - ★ 火力 —— 提升子弹速度，满级可击穿钢墙
  - 💣 炸弹 —— 消灭场上所有敌人
- 多关卡（难度递增）、计分、音效

## 运行

直接用浏览器打开 `index.html`，或启动一个本地服务器：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 在线试玩

通过 GitHub Pages 部署后即可在线游玩（仓库 Settings → Pages → 选择 main 分支）。
